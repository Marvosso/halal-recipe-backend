## Detailed Feature Rationale

### Free Tier Features (Must Be Meaningful)

#### ✅ Unlimited Basic Recipe Conversion
**Rationale**: Core functionality must be free. Users need to convert recipes to see value.

**Limit**: None (unlimited)

**Why Free**: 
- Primary use case - users won't pay if they can't try it
- Builds trust and demonstrates value
- Drives organic growth through word-of-mouth

---

#### ✅ Top 2 Substitution Alternatives
**Rationale**: Free users get real value, but premium gets all options.

**Limit**: Show top 2 alternatives (not all)

**Why This Limit**:
- 2 alternatives is usually enough for most users
- Creates clear upgrade incentive (see all options)
- Doesn't feel restrictive (still helpful)

**Premium Benefit**: See all alternatives (often 3-5 options)

---

#### ✅ Up to 10 Saved Recipes
**Rationale**: Enough for casual users, but power users need more.

**Limit**: 10 saved recipes

**Why This Limit**:
- Most users save 5-8 recipes
- 10 feels generous (not restrictive)
- Clear upgrade path for recipe collectors
- Doesn't block core functionality

**Premium Benefit**: Unlimited saves + collections + search

---

#### ✅ Basic Halal Verification
**Rationale**: Core feature - all users need ingredient checking.

**Includes**:
- Ingredient-level checking
- School of thought preferences
- Strictness levels
- Basic explanations

**Why Free**: 
- Primary value proposition
- Users won't pay if basic checking isn't free
- Builds trust in the platform

**Premium Benefit**: Brand-level verification (check specific products)

---

#### ✅ Text Export
**Rationale**: Basic sharing needs to be free.

**Why Free**:
- Users need to copy/share converted recipes
- Basic functionality
- Doesn't cost us anything

**Premium Benefit**: PDF (formatted) + JSON (meal planning apps)

---
