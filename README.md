\# Halal Recipe Converter (MVP)



Minimal MVP that converts pasted recipes into halal-compliant versions.



\## Purpose

\- Investor demo

\- User validation



\## Stack

\- Frontend: React

\- Backend: Node.js + Express

\- Halal logic: Rule-based

\- AI: Parsing \& rewriting only



\## Disclaimer

This is not a fatwa.
